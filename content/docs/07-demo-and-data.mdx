This chapter is for DSO teams. The commercial team can use the demo path to show the full offer in about ten minutes. The data teams can see where each figure comes from, which figures are confirmed, and what DSO must supply before the November opening.

## A ten minute demo covers the offer, the proof and the action

<StepList>
<Step number={1}>**Start wide.** Open LOD 1 and read the district figures along the bottom.</Step>
<Step number={2}>**Show the offer.** Go to LOD 3 in Future. Select District IO and walk through the phases.</Step>
<Step number={3}>**Go to a building.** Select Phase 1A, then 1A-1, then Techno Lab Block.</Step>
<Step number={4}>**Show what is available today.** Switch to Now and select TechnoHub 4. Open Building Info.</Step>
<Step number={5}>**Go inside.** Select View interior, then drop the pin for street view.</Step>
<Step number={6}>**Show the record.** Switch to Past and step from 2010 to 2026.</Step>
<Step number={7}>**Close.** Select Enquire and show the form.</Step>
</StepList>

## Every figure has one of three statuses

| Status | Meaning | Action |
|---|---|---|
| Confirmed | From a DSO document | None |
| Indicative | A realistic placeholder | Replace when DSO connects the data |
| Placeholder | Content from another source, for layout only | Replace before any public use |

## Data sources

| Data | Source | Status |
|---|---|---|
| District IO areas, homes, hotel keys, phase GFA | DSO HQ Concept Design Stage Report (CPG Middle East) | Confirmed |
| Asset types | DSO Master Plan Land Use, August 2026 | Confirmed |
| Transport stops (27) | DSO Bus Stops drawing | Confirmed |
| Cycling track length | DSO Jogging and Bicycle Track drawing | Length to confirm |
| Delivery years and delivery track | None. The report gives phases, not dates. | Indicative |
| Rent, availability, occupancy, suites | None. Needs a leasing feed. | Indicative |
| Building level live data | Building management system | Indicative |
| Environment readings, solar, EV, parking | DSO data lake | Indicative |
| CCTV feeds | DSO camera list | Placeholder |
| Sub-phase and building data | None. The report gives areas by phase. | Indicative |
| Innovation sites | None | Indicative, only labs shown |

<Step number={2}>Put the PNGs in raw-images in the repo.</Step>
