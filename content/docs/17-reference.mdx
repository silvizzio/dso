This chapter collects the terms, measures and sources behind the platform. Buyers can use it to read the figures correctly. DSO teams can use it to see which figures are final and what is still needed before the November opening.

## Glossary

The platform and this guide use a small set of property and design terms. Each one is defined here once.

| Term | Definition |
|---|---|
| AOI | Area of interest. One of the four areas the platform features. |
| LOD | Level of detail. One of the three zoom levels of the map. |
| Phase | A delivery stage of District IO (1A, 1B, 1C, 1D, 2), designed, built and handed over as one package. |
| Sub-phase | A part of a phase, for example 1A-1. |
| G+n | Ground floor plus n floors. G+5 is six storeys. |
| Concept design | The first formal design stage. It fixes the mix of uses, the phases and the rough building shapes. |
| Completion | The date construction finishes. |
| Handover | The date a tenant or buyer gets the keys. Usually after completion. |
| Off-plan | A sale or lease agreed before the building is complete. |
| Under offer | Space with an offer in progress. |
| Floor plate | The floor area of one standard floor of a building. |
| BMS | Building management system. The software that runs cooling, lighting and power. |

## Area measures

Property figures use several area measures, and they are not interchangeable. A "1,000 m² office" can mean different amounts of usable space, depending on the measure. The table defines each measure and gives the District IO value.

![the district figures at LOD 2, which use GFA for floor area alongside homes and hotel keys](/dso/api/img/02-lod2-dso-1.jpg)

| Measure | Definition | District IO |
|---|---|---|
| Plot area | Land area of the site | 164,420 m² |
| GFA | Gross floor area. Total floor area inside the building walls. | 595,300 m² |
| GLA | Gross leasable area. Floor area a tenant can lease. | 429,000 m² |
| BUA | Built-up area. All built floor area, including parking and services. | 991,689 m² |

Two ratios help to read these figures. GLA is 72% of GFA, so about a quarter of the floor area goes to lobbies, cores, corridors and plant. BUA is about 1.7 times GFA, because it also counts parking and building services.

## Every figure has one of three statuses

Not every figure on the platform is final. Each one has a status, so that nobody quotes a placeholder as a fact.

| Status | Meaning | Action |
|---|---|---|
| Confirmed | From a DSO document | None |
| Indicative | A realistic placeholder | Replace when DSO connects the data |
| Placeholder | Content from another source, for layout only | Replace before any public use |

## Data sources

| Data | Source | Status |
|---|---|---|
| District IO areas, homes, hotel keys, phase GFA | DSO HQ Concept Design Stage Report (CPG Middle East) | Confirmed |
| Asset types | DSO Master Plan Land Use, August 2026 | Confirmed |
| Transport stops (27) | DSO Bus Stops drawing | Confirmed |
| Cycling track length | DSO Jogging and Bicycle Track drawing | Length to confirm |
| Delivery years and delivery track | None. The report gives phases, not dates. | Indicative |
| Rent, availability, occupancy, suites | None. Needs a leasing feed. | Indicative |
| Building level live data | Building management system | Indicative |
| Environment readings, solar, EV, parking | DSO data lake | Indicative |
| CCTV feeds | DSO camera list | Placeholder |
| Sub-phase and building data | None. The report gives areas by phase. | Indicative |
| Innovation sites | None | Indicative, only labs shown |

## Open items before the November opening

These items need data or a decision from DIEZ or DSO. Each one turns an indicative figure into a confirmed one.

| Item | Owner |
|---|---|
| Programme dates for each phase | DIEZ |
| Leasing feed: rent, availability and suites | DSO |
| Camera list and feed access | DSO |
| Data lake access for live readings | DSO |
| Interior renders for the virtual tour | DSO |
| Confirmed innovation programmes | DSO |
| Enquiry destination (CRM or email) and QR link | DSO |
